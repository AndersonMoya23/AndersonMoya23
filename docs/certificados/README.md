# Documentos públicos

Esta carpeta está reservada para los certificados que reciban aprobación explícita para publicación.

## Estado actual

No hay archivos públicos aquí. Los PDF originales se encuentran fuera del repositorio y no han sido copiados ni subidos.

## Cómo publicar un certificado aprobado

1. Copiar el PDF autorizado a esta carpeta con un nombre claro, por ejemplo `itla-alfabetizacion-ia-2026-10-06.pdf`.
2. Evitar nombres que incluyan cédulas u otros identificadores personales.
3. Añadir la referencia en la sección `06 / CERTIFICACIONES` de `../index.html`.
4. Verificar que el archivo no contenga datos personales que no se deseen publicar.
5. Confirmar el despliegue con la guía `../DEPLOY.md`.

Los datos de los certificados (nombre del curso, emisor y fecha) ya aparecen en el portafolio sin necesidad de publicar los documentos.
